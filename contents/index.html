Evaluator notes

Runtime contract and current boundaries

This is the model implemented by the current code, not a target architecture diagram. The server remains one process; only CGI execution forks a child.

FD ownership

Poller owns one poll() set for listening sockets, client sockets, and parent CGI pipe ends. Worker dispatches the resulting readiness events.

Connection state

Each client has a Connection with input/output buffers, write cursor, keep-alive policy, listener-selected server index, and one Transaction.

I/O rule

Socket and pipe descriptors are non-blocking. Reads and writes happen only after readiness, and their return values drive control flow without inspecting errno.

CGI boundary

CgiJob owns the child PID and pipe progress. Handler and script target are distinct; the script path is checked beneath the route root before execve.
