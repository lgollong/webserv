The working path

A request stays in one loop

  1. 01BrowserA request reaches a listener.
  2. 02PollerReadiness decides the next I/O step.
  3. 03HandlerStatic, CGI, redirect, upload, or session.
  4. 04ResponseHTTP bytes flush without blocking the loop.
